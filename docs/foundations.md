# Scientific specifications and traceability

All finite-state APIs use integer state indices starting at zero. Rows of a stochastic matrix sum to one. A row distribution evolves by right multiplication. Inputs with negative probabilities are rejected. Numerical checks use absolute tolerances; exact graph reachability uses strictly positive transitions. The largest benchmark sample in this milestone is 10,000 independent paths per model, generated with NumPy's Generator.

| ID | Public entry points | Specification and independent reference | Cost and limits |
|---|---|---|---|
|01|MarkovChain, validate_transition_matrix|Multi-step transition is a chronological product. A schedule contains subsequent matrices after the initial transition. Two noncommuting matrices test order. Seeded path frequencies are checked against matrix powers.|Dense homogeneous powers cost O(n³ log k). Sparse powers can fill in.|
|02|line_walk, grid_walk, graph_walk, lattice_paths, path_statistics, occupation_times|Graph moves are proportional to outgoing weights. Reflection holds an attempted out-of-range step at the endpoint. A cycle wraps. Lattice paths choose one coordinate per step. Verify binomial return mass and variance at fixed time.|Lattice output requires O(paths × time × dimension) storage. Grid indices are row-major.|
|03|classify_states|Strongly connected components give communicating classes. A closed finite class is recurrent. Period is the gcd of directed cycle lengths. Zero denotes a singleton with no return path.|SCC discovery is linear in vertices and edges. Classification is finite-state only.|
|04|recurrence, return_generators, eventual_line_return, line_return, lattice_recurrence|First return begins at step one. G(z) is a diagonal resolvent entry, F(z)=1−1/G(z). A biased line has eventual return 2 min(p,1−p). Symmetric nearest-neighbour walks on integer lattices are recurrent in dimensions one and two.|Dense resolvent costs O(n³). Lattice classification uses the analytic infinite model.|
|05|absorption, line_walk|For transient block Q solve (I−Q)N=I. Visits=N, mean=N1, class-entry probabilities=NR. Output columns follow the returned class order. The fair gambler on 0…b has upper-exit probability i/b and mean i(b−i).|Dense O(n³). Closed classes are terminal sets, including non-singletons.|
|06|hitting, passage_distribution, empirical_passage|Hitting includes time zero. For reachable nontarget states solve (I−Q)p=r then (I−Q)m=p. Conditional mean=m/p, undefined at p=0. Eventual failure gives infinite unconditional mean. Output mass is indexed by time then start. Censored paths report last observed time and a flag.|Dense eventual solves O(n³), finite horizon O(kn²). Fixed targets within each calculation.|
|07|stationary_distributions, iterate, detailed_balance|One normalized stationary law per closed class, with all stationary laws given by their convex hull. Linear and eigenvector solvers are compared. Cesàro includes times 0 through k.|Dense O(n³). Ill-conditioned chains require residual review.|
|08|distances, mixing_time, reversible_bound|Worst-start TV threshold from exact finite powers; None means threshold unobserved by horizon. Absolute spectral gap and TV bound require irreducibility and detailed balance. KL may be infinite.|Mixing search costs O(kn³). Periodic and reducible chains are rejected by this mixing-time API.|
|09|ContinuousChain, birth_death|Exit rates determine exponential waiting times. Uniformization sums Poisson-weighted powers with omitted tail bounded by tol. Compare against a two-state closed form and independent event simulation. Finite-capacity M/M/1 queues use constant birth/death edge rates.|Dense exponential costs O(n³). Uniformization cost grows with rate × time. No infinite queue truncation guarantee.|
|10|LevyProcess|Drift plus Brownian noise plus compound Poisson jumps, with deterministic or Gaussian jump sizes. Paths return aggregate jump counts for each interval. Characteristic exponent combines independent component exponents. Test empirical characteristic function and moments.|O(paths × intervals). General stable and infinite-activity jump simulators are outside this implementation.|
|11|graph_operators, hamiltonian|Degree uses row sums. L=D−A; normalized L uses zero inverse degree at isolates. Select adjacency or Laplacian Hamiltonian explicitly. Complex Hermitian adjacency is accepted by the adjacency Hamiltonian API.|Sparse construction scales with stored entries. Directed real adjacency alone generally fails hermiticity.|
|12|spectrum, spectral_diagnostics|Hermitian full or lowest partial spectrum, residual and orthogonality error. Degeneracy is assessed by adjacent eigenvalue separation; projectors use the selected basis. Complete-graph and star spectra admit exact references.|Dense O(n³). Sparse partial spectra may cut through a degenerate block. Full projectors require the complete block. Conditioning uses an explicit numerical zero threshold.|

The executable reference checks are in tests/test_foundations.py. The benchmark records the sample standard error as sample SD divided by the square root of the number of independent paths. Its stopped-time estimate is restricted to 320 steps; the analytic reference is the unrestricted mean, and the censor count is reported. Timings are local observations, not throughput guarantees. Direct linear solves, underflow in rare event probabilities, and finite precision limit accuracy near singularity. No hardware experiment or cloud computation is used by the library.

## References

- Levin and Peres, with contributions by Wilmer, *Markov Chains and Mixing Times*, second edition. Finite chains, stationarity, coupling and spectral bounds.
- Norris, *Markov Chains*. Classification, hitting times and continuous-time chains.
- [Pólya's random walk constants](https://mathworld.wolfram.com/PolyasRandomWalkConstants.html). Infinite-lattice return benchmarks.
- Chung, *Spectral Graph Theory*. Normalized graph Laplacians and eigenvalues.
