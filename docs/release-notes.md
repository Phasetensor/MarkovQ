# MarkovQ 0.1.0 — release notes

The initial scientific Python distribution covers 25 functional areas in classical Markov processes, spectral graph methods, quantum dynamics and applied numerical experiments. Public entry points, benchmark protocols, independent references and known numerical limits are indexed in the README. The core uses NumPy and SciPy. Qiskit, QuTiP and the three PhaseTensor integrations are optional.

Search results use log-probabilities for candidate selection. Detection diagnostics distinguish defective and unresolved expectations. Experiment exports preserve tagged nonfinite scientific outcomes. Partition execution verifies simulation inputs, and circuit reports distinguish active physical wires from backend capacity. All hardware-adapter evidence comes from simulation.

The release workflow builds the tagged version once. Its wheel and source distribution share the same SHA-256 manifest on GitHub and are submitted unchanged to PyPI.
